Sprint 0.5.5 harmonise l’interface et améliore les commandes serveur et l’aperçu web.

- **Interface** : boutons dans le thème, états vides partagés, tableau des ports sur une surface uniforme avec bordures arrondies, en-tête d’aperçu compact.
- **Serveurs** : bouton Redémarrer, progression visible et protection commune contre les doubles clics. Un arrêt échoué bloque le lancement du remplaçant. Les arrêts inattendus affichent le code de sortie et donnent accès aux logs.
- **Aperçu** : serveur, adresse, format, dimensions libres et zoom mémorisés entre les pages et après rechargement.
- **Entretien** : anciens composants et images inutilisés supprimés, paramètres et styles découpés, préférences Portly/Sprint centralisées. La copie du chemin de projet signale les succès et erreurs.

Validation : 138 contrôles UI et 32 contrôles des actions serveur avec serveurs simulés, 11 tests Rust, lint et build Windows réussis. Vérification visuelle en thèmes clair et sombre, fenêtre réduite et texte agrandi.

Téléchargements Windows x64 :

- **Sprint_0.5.5_x64-setup.exe** : installateur recommandé, également utilisé par la mise à jour intégrée.
- **Sprint_portable_0.5.5_x64.exe** : exécutable autonome, à lancer sans installation ; nécessite Microsoft Edge WebView2 Runtime sur le poste.
- **SHA256SUMS.txt** : empreintes SHA-256 des deux exécutables.
